## ✨ Overview

This portfolio serves as a central space to explore my academic background, technical work, research interests, and professional journey.

It combines a minimal visual design with interactive elements to create an engaging experience across desktop, tablet, and mobile devices.

## 🚀 Features

- **Responsive Design:** Optimized layouts for mobile, tablet, and desktop screens.
- **Interactive Hero Section:** Animated background, profile presentation, and quick-access professional links.
- **About & Quick Stats:** Highlights academic achievements, research contributions, and technical milestones through interactive cards.
- **Research Showcase:** An interactive research archive featuring paper navigation and document viewing.
- **Projects Section:** A curated presentation of selected development and AI/ML projects.
- **Professional Experience:** Highlights internships and professional experience, including Indian Army (DGIS) and Quest Global.
- **Certification Archive:** An interactive archive-style interface for exploring professional certifications.
- **Smooth Animations:** Motion effects and transitions for an engaging browsing experience.
- **Interactive Navigation:** Responsive navigation with a dedicated mobile menu.
- **Contact Section:** A direct way to connect professionally.

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/PriyankaAsthana/YOUR-REPOSITORY-NAME.git
```

2. Navigate into the project directory:

```bash
cd YOUR-REPOSITORY-NAME
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.

## 🎨 Design Philosophy

The portfolio follows a clean, contemporary design approach inspired by modern product interfaces.

Key design considerations include:

- Minimal and structured layouts.
- Consistent typography and spacing.
- Subtle gradients and visual depth.
- Purposeful animations and transitions.

- Accessibility-conscious navigation and controls.
